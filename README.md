# meletaó

A calm, private-first gratitude and reflection platform. Users can write gratitude entries, keep them private, or make them public anytime.

## Tech stack
- Next.js (App Router)
- TypeScript

## Getting started

### Install dependencies
```bash
npm install
```

### Run the app
```bash
npm run dev
```

Open `http://localhost:3000`.

## Development notes
- Pages live in `app/`
- UI components live in `components/`
- Shared utilities live in `lib/`
